Temple Escape — a fully custom playable

No game engine. A match-3 rescue playable written from an empty folder on Pixi.js 8, Three.js and GSAP over a Vite/Node toolchain — 20 modules, ~8,300 lines, mobile-first and responsive, shipping as a single self-contained 2.93 MB file.

  • Custom debris physics — a headless simulation with its own unit tests, separated from the Pixi renderer that draws it.
  • Hand-written VFX — rope, confetti, dust, sparkle and shine, each its own module.
  • Three.js character rig composited into the 2D Pixi scene.
  • Own art pipeline tool — a sharp-based optimiser that gets the whole creative under the size budget.
  • Traced and documented a silent failure in the playable SDK, where missing build-time defines made every CTA fall through to window.open("").

Tools & pipeline

  • Electron production tool built around the studio playable template — generates particle emitters and strips repetitive setup out of production.
